Power BI dashboard starter pack
1. Open Supply_Chain_Inventory_Analytics.xlsx from the earlier project pack.
2. Import Order_Fact, Inventory_Snapshot, Supplier_Scorecard into Power BI Desktop.
3. Follow Dashboard_Build_Guide.md to create the single-page report.
4. Copy measures from Supply_Chain_DAX_Measures.txt into Power BI.
Note: A native .pbix file cannot be authored by this pack; build/save the report in Power BI Desktop.
